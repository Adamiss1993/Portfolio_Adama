### Création d’un outil pour déterminer la localisation optimale

Création d’un outil pour déterminer la localisation optimale d’un
camping dans la commune de Nice ; les décideurs n’ont pas encore déterminé
précisément les différentes contraintes et souhaiteraient avoir un outil à leur
disposition afin de faire un ensemble de tests pour visualiser différentes
possibilités
