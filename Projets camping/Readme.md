### Création d’un outil pour déterminer la localisation optimale

Création d’un outil pour déterminer la localisation optimale d’un
camping dans la commune de Nice ; les décideurs n’ont pas encore déterminé
précisément les différentes contraintes et souhaiteraient avoir un outil à leur
disposition afin de faire un ensemble de tests pour visualiser différentes
possibilités.

## Contraintes :
- Le camping doit être localisé à moins de **100 mètres d’une rivière**
- Le camping doit être localisé à moins de **20 mètres d’une route**
- Le camping doit être localisé au sein d’une **parcelle orientée Sud**
  - sud
  - sud-est
  - sud-ouest
- Le camping doit être localisé au sein d’une parcelle dont la **pente est inférieure à 20 degrés**
  - codes **1, 2 ou 3**
- La parcelle doit appartenir à la **ville de Nice**
  - code propriétaire : `+00510`
- La parcelle doit avoir une **surface supérieure à 2000 m²**
